# Knee-d Help · 膝关节居家康复AI训练 Demo

> 香港黑客松演示版：普通摄像头 + 浏览器本地姿态识别。
> 支持**坐站训练**与**仰卧直腿抬高训练**两种康复动作的实时计数、达标判定与错误姿态提示。
> 训练推理无需后端、无需联网、无需 GPU，视频全程不上传。

**核心特性**
- 🏠 左侧导航五模块布局（v5）：首页 / 康复训练 / 训练记录 / 康友圈 / 语音陪伴，单页无刷新
- 🪑 坐站训练（侧面拍摄）：站→坐→站自动计数，膝关节角度检测 / 幅度不足实时提示
- 🛏️ 仰卧直腿抬高训练：放→抬→放自动计数，膝盖弯曲 / 高度不足实时提示
- 🦴 17 点人体骨架实时叠加显示，关键关节角度标注
- 🔊 语音播报计数与错误提示（可关闭），大字体适老化界面
- 👥 实验性多人检测开关（最多 3 人同时计数）
- 📋 训练记录（v5）：每次训练自动保存历史，首页展示连续天数 / 累计次数 / 今日概览
- 💬 朋友圈式康复社群（v4）：训练成果分享、点赞鼓励、文字/语音评论，本地账号模拟
- 🎙️ 双语语音控制（v4）：按住说话即可语音操控训练，支持普通话 / 粤语
- 🗣 LiveKit 多人语音房间（v4，可选）：康复师带练、同伴语音鼓励，断网自动降级模拟语音

## 二、快速开始（三步）

**第 1 步：确认收到完整文件**（缺一不可）

```
项目文件夹/
├── index.html          ← 页面（单文件）
├── yolo11n-pose.onnx   ← AI 姿态模型（约 12MB）
├── ort/                ← 推理运行库（5 个文件，约 40MB）
└── README.md
```

**第 2 步：在项目文件夹内启动本地服务器**（推荐方式一）

```bash
cd 项目文件夹
python -m http.server 8000
```

**第 3 步：浏览器打开 http://localhost:8000**

1. 首次打开在**首页**输入昵称完成登录（本地账号，之后自动识别身份；首页用户卡片会显示连续训练天数与累计次数）
2. 浏览器弹出摄像头权限请求时点击**允许**
3. 左侧导航点击「康复训练」→ 选择动作卡片 → 等待状态角标变绿 → 点击「开始训练」
4. 底部导航栏「设置」可开关语音播报、多人检测，切换语音识别语言（粤语/普通话/英语）与界面文字（简体/繁体/英文）

> ⚠️ **不能直接双击 index.html 打开！** 必须通过 `http://localhost` 访问，否则模型加载和摄像头调用都会失败（浏览器安全限制）。

## 三、启动服务器的三种方式（任选其一）

### 方式一：Python（推荐，最通用）

```bash
# Windows / macOS / Linux 通用，Python 3 任意版本
python -m http.server 8000
```

- 未安装 Python：到 [python.org](https://www.python.org/downloads/) 下载安装（Windows 安装时勾选 *Add Python to PATH*）
- 8000 是端口号，被占用时可换成 8080 等任意数字，浏览器地址同步修改

### 方式二：VS Code + Live Server（适合有 VS Code 的人）

1. VS Code 打开项目文件夹
2. 安装扩展 **Live Server**
3. 右键 `index.html` → **Open with Live Server**（会自动开浏览器）

### 方式三：Node.js（适合有 Node 的人）

```bash
npx serve .
# 或
npx http-server -p 8000
```

> 三种方式效果完全相同，只是「用哪个程序把文件以 HTTP 方式发出来」的区别。

## 五、使用指南

### 训练流程

1. 左侧导航进入「康复训练」，选择动作卡片（坐站训练 / 仰卧直腿抬高训练）
2. 等待骨架出现（绿色「准备就绪」角标）
3. 点击**开始训练**（统计清零，开始计时）
4. 按要领完成动作，屏幕实时显示次数与提示
5. 点击**结束训练**，查看结果卡片（总次数、达标率、时长、鼓励文案），可分享到康友圈

### 训练记录

- 每次结束训练自动保存一条记录（日期、动作、完成次数、达标率、时长），存入 localStorage。
- 记录按时间倒序排列，点击卡片可展开查看详情；没有记录时显示空状态提示。
- 首页自动统计：连续训练天数、累计完成次数、今日完成次数与达标率。

### 坐站训练

- **拍摄**：摄像头在**身体正侧面**约 2 米，高度对准膝盖，肩、髋、膝、踝全部入镜；坐在无扶手椅子上，双脚与肩同宽
- **动作**：站起至膝盖伸直（≥160°）→ 完全坐下（≤100°）→ 站起，计 1 次
- **达标**：一次动作同时达到两个角度阈值
- **错误提示**：
  - 只蹲一半就站起 → 「动作幅度不足，请完全坐下再站起」

### 仰卧直腿抬高训练

- **拍摄**：仰卧平躺，摄像头在**身体侧面**约 2 米，肩、髋、膝、踝全部入镜
- **动作**：膝盖伸直，缓慢抬腿至 45° 以上 → 缓慢下放至 20° 以下，计 1 次
- **达标**：抬到 45° + 下放到 20° + 全程膝盖 ≥150°，三者同时满足
- **错误提示**：
  - 膝盖弯曲 <150° → 「请保持膝盖伸直，用大腿发力」
  - 未到 45° 就下放 → 「抬高高度不足，请再往上抬一点」

## 六、常见问题排查

| 现象 | 处理 |
|---|---|
| 左上角红色「模型加载失败」 | ① 确认 `yolo11n-pose.onnx` 与 index.html 同目录；② 确认是通过 `http://localhost:8000` 打开（不是双击文件）；③ 确认 `ort/` 目录完整；④ 把页面红框里的「错误详情」发给开发者 |
| 左上角红色「ONNX Runtime 库加载失败」 | `ort/ort.min.js` 缺失或损坏，重新解压完整包 |
| 无法打开摄像头 | 浏览器地址栏左侧允许摄像头权限 → 点「重试」；检查摄像头是否被微信/腾讯会议等占用；必须用 localhost 或 HTTPS 访问 |
| 一直「未检测到人体，请调整位置」 | 光线充足；全身入镜（约 2 米距离）；衣服与背景颜色有对比；参考页面上方的拍摄提示 |
| 计数不灵敏 | 幅度要做满：坐站必须到 100°/160° 两端；直腿抬高必须过 45° 且完全下放 |
| 语音不播报 | 先点一下页面任意按钮（浏览器要求用户交互后才允许发声）；确认「语音播报」已勾选 |
| 页面还是旧版 | **Ctrl+F5 强制刷新**；页脚应显示 **v2** 字样 |
| 手机能不能用 | 可用手机浏览器访问，但仰卧动作的手机机位摆放较困难，演示建议用电脑 |

## 七、给开发者

### 可调参数

所有判定阈值与功能开关集中在 `index.html` 顶部 `CFG` 常量：站立/坐态角度、抬起/下放角度、膝盖伸直阈值、平滑帧数（5）、推理帧间隔（2）、社群/语音控制/LiveKit 开关与密钥等，改一处即可生效。

### 更新页面后记得加缓存版本号

`index.html` 中 `ort/ort.min.js?v=9` 的 `?v=9` 用于强制刷新浏览器缓存，**每次修改页面后递增该数字**（页脚版本标记同步更新），否则他人可能打开缓存的旧页面。

### 重新导出模型（一般不需要）

```bash
# 本机 Anaconda 环境旧版 MSVC DLL 会导致 onnx 崩溃，
# export_model.py 已内置 libs/ 新版运行库预加载修复
python export_model.py   # 生成 yolo11n-pose.onnx（opset=12 + simplify）
```

模型固定约定：输入 `images [1,3,640,640]` NCHW，输出 `output0 [1,56,8400]`（4 框 + 1 置信度 + 51 关键点，坐标为 640 输入空间绝对像素，已含解码）。

## 八、v4/v5 新增功能使用说明

### 1. 康友圈

- **入口**：左侧导航「💬 康友圈」或首页大卡片；训练结束的结果卡片点「📤 分享到康友圈」可直接把训练成果发布为动态。
- **账号（全局）**：打开页面即先注册昵称，用于训练记录、社群互动与语音房间身份（存于浏览器 localStorage），下次打开自动登录；页面头部与社群顶部都会显示当前昵称。社群功能未登录到账号时不会出现，账号是全局唯一的。
- **发布动态**：文字输入后点「发布」；或按住「🎤 按住说话」用粤语/普通话说一段话，松开自动转成文字，可编辑后再发布。点「🖼️ 图片」可从本地选图（每条最多 3 张），图片经 canvas 压缩后与文字/语音组合成同一条动态展示。
- **互动**：每条动态可「👍 鼓励」点赞；评论区默认直接展开，支持文字或按住说话评论。
- **个人主页（v7）**：左侧导航「👤 我的」进入个人主页，展示昵称、训练统计与我的动态数，支持「✏️ 修改昵称」；点击头像可从本地选图压缩后设为自定义头像，全站头像即时同步。
- **预置氛围**：代码内置 6 条模拟同伴动态（不同昵称、训练成果与文案），与自己的动态混合按时间倒序展示。`CFG.COMMUNITY_SEED` 可关闭。
- **数据说明**：动态/评论/点赞存 localStorage（`kneed_*` 键），换浏览器或清缓存即丢失，属 Demo 级本地模拟；接入 Supabase 等后端时只需替换代码中 `Store` 存储层实现。

### 2. 全局语音控制（按住说话）

- 右下角悬浮紧凑按钮「按住说话·语音控制」（带呼吸光晕，不遮挡主界面）：**按住**说话，**松开**自动识别并执行；屏幕中央弹出「已执行：XXX」提示条，2 秒自动消失。
- **普通话 / 粤语自动识别**：无需任何切换，想说什么语言就说什么语言——系统先用首选语言识别，没识别出有效指令就**自动换另一种语言再听一次**（设置弹窗中的语言选项只是首选语言偏好）。
- 支持的指令（关键词匹配，普通话/粤语均可）：
  - 开始训练 / 结束训练
  - 切换坐站训练 / 切换直腿抬高（说「坐站」「直腿抬高」即可）
  - 打开语音播报 / 关闭语音播报
  - 页面跳转：康复训练 / 训练记录 / 语音陪伴 / 康友圈（说「社群」「朋友圈」）/ 返回首页
  - 切换字体 / 切换繁体 / 切换简体（界面文字繁简转换）
- 只做按住触发式识别，不做后台连续监听，避免误触发。
- 浏览器不支持语音识别（如 Firefox/Safari）时按钮自动隐藏，不影响任何功能。

### 3. 语言切换（普通话 / 粤语）

左下角「⚙️ 设置」弹窗与屏幕底部语音控制栏都有「粤语 / 普通话」切换按钮（两处联动），默认**粤语**（`CFG.VOICE_LANG`），语音输入、语音评论、语音控制共用此设置。

### 4. 简体 / 繁体 / 英文界面切换（v8 三语循环）

- **侧边栏常驻**「繁體 / English / 简体」切换按钮（显示的是点击后切换到的下一语言名），点击依次循环 简体 → 繁体 → 英文 → 简体，全界面文字（训练提示、社群动态、按钮、弹窗、placeholder、语音播报）整体切换，偏好自动记忆（localStorage）；「⚙️ 设置」弹窗内也有同样的切换按钮。
- 繁体模式下自动改用繁体友好字体（微軟正黑體 / PingFang TC / Noto Sans TC）；英文模式使用英文友好字体（Segoe UI / system-ui）。
- **英文界面下自动英文朗读与识别**：悬浮朗读用英语语音（en-US）；语音控制支持英语指令（如 "start training"、"sit to stand"、"community"、"switch language"）；康友圈按住录音转文字按「界面语言优先 + 粤语 + 英语」链自动重试识别，识别出哪种语言就转写哪种文字。
- 繁体转换基于 opencc-js 库，**本地文件随压缩包分发（`libs/opencc-js.full.js`，离线可用）**；本地缺失时自动尝试 CDN 加载，两者都失败则繁体不可用（按钮循环退化为 简体 ↔ 英文），不影响其他功能。`CFG.ENABLE_ZH_CONVERT: false` 可关闭繁体；`CFG.ENABLE_EN: false` 可关闭英文。

### 5. 语音陪伴（LiveKit 多人语音房间，可选加分项）

- **申请（LiveKit Cloud 免费版）**：
  1. 打开 <https://cloud.livekit.io> 注册 / 登录；
  2. Create Project → 创建项目（免费额度足够黑客松演示）；
  3. 进入项目 **Settings → Keys**，复制：
     - WebSocket URL（形如 `wss://xxxx.livekit.cloud`）
     - API Key
     - API Secret
  4. 填入 `index.html` 顶部 CFG 配置的 `LIVEKIT_URL` / `LIVEKIT_API_KEY` / `LIVEKIT_API_SECRET`（代码中已标注「← 替换处」）。
      - 复制后填入 `index.html` 顶部 CFG 的 `LIVEKIT_URL` / `LIVEKIT_API_KEY` / `LIVEKIT_API_SECRET` 即可（README 不保存明文密钥）。
- **使用（v9 手动加入）**：左侧导航进入「语音陪伴」页面**不再自动加入**，页面显示「🎧 加入语音房间」与「🎭 模拟语音演示」两个按钮，由用户自主选择：
  - 点「🎧 加入语音房间」→ 以本地账号（昵称+ID）加入真实 LiveKit 语音房间，**默认静音**；连接限时 15 秒（`CFG.LIVEKIT_JOIN_TIMEOUT`），超时/失败提示并回到待加入状态，**不会一直停在「正在连接」**。
  - 点「🎭 模拟语音演示」→ 进入本地模拟语音房间（虚拟成员 + 预置聊天消息），适合无网络/未配密钥的演示场景；可点「🚪 退出模拟」随时退出回到待加入状态。
  - 加入后：顶部显示房间状态与当前时间，中部成员网格（说话人青色高亮 +「正在说话」标注，康复师显示「主持人」标签，静音成员显示静音角标），中下部消息区显示成员消息，底部大按钮：静音/取消静音、举手（广播给所有成员）、扬声器开关、退出房间；离开页面自动退出。
- **康复师标签**：昵称为 `CFG.TEACHER_NAME`（默认「康复师」）的成员在房间中显示「主持人」标签。
- **模拟语音内容**：模拟模式下用浏览器 TTS 朗读康复师指导语与同伴鼓励语（台词在 `CFG.SIM_VOICE_LINES`，可换成真人录音），英文界面下自动说英文；演示不会翻车。`CFG.ENABLE_LIVEKIT: false` 可整体关闭真实房间（「模拟语音演示」按钮仍可用）。
- ⚠️ 安全说明：demo 采用浏览器前端签发 JWT（密钥在页面源码中可见），**正式环境必须在后端签发 token**；LiveKit SDK 从 CDN 加载，语音房间功能需要联网。

### 6. 降级开关速查（全部在 `index.html` 顶部 CFG）

| 开关 | 作用 |
|---|---|
| `COMMUNITY_ENABLED` | 关闭社群广场（入口与分享按钮隐藏） |
| `COMMUNITY_SEED` | 关闭预置模拟动态 |
| `ENABLE_VOICE_CONTROL` | 关闭全局语音控制按钮 |
| `ENABLE_LIVEKIT` | 关闭语音房间（连模拟语音一起关闭） |
| `VOICE_LANG` | 语音识别默认语言（`zh-HK` 粤语 / `zh-CN` 普通话 / `en-US` 英语） |
| `ENABLE_ZH_CONVERT` | 关闭繁体界面（切换按钮循环退化为 简体 ↔ 英文） |
| `ENABLE_EN` | 关闭英文界面 |
